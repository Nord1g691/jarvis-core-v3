# JARVIS Core V3

Nouvelle base propre et indépendante pour JARVIS Core V3.

## Installation HACS

Ajoutez ce dépôt comme **dépôt personnalisé** dans HACS et choisissez **Integration**.

Repository: https://github.com/Nord1g691/jarvis-core-v3

## Structure

L'intégration Home Assistant se trouve dans `custom_components/jarvis`.

## Objectifs V3

- HUD JARVIS fidèle au visuel validé
- Catégories énergie : Production, Consommation, Import, Export
- Bouton ← Retour
- Intégration Home Assistant propre
- Configuration robuste
- Calcul cohérent des flux énergie à partir de la production et de la consommation lorsque possible
- Aucun impact sur JARVIS Core V2

Chaque étape importante sera publiée dans un commit séparé afin de pouvoir revenir en arrière sans perdre le travail.
